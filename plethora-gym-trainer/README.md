# Plethora Bits

Mobile-first interactive Bits for [Plethora](https://create.plethora.studio),
built against the `plethora-bit@2` runtime.

| Bit | What it is |
| --- | --- |
| [`plethora-gym-trainer`](plethora-gym-trainer) | A training week with an animated coach: setup and train reels, travel endpoints, and a date-ticked calendar. |
